# Kindergarten Reservation System – Frontend

This is the frontend of a volunteer project designed to help kindergartens manage daily attendance and reservations. The application is built in **React** with **Tailwind CSS** for styling and uses **React Router** for navigation.

The backend is already integrated, and we're actively developing more features over the coming months.

---

## 🖥️ Current Functionality

- **Child selection** – choose a registered child to view their data
- **Monthly attendance overview** – view attendance by month
- **Attendance status display** – see which days are attended, absent, or pending
- Fully connected to a working backend built with Spring Boot
